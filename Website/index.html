Features

What Ink-boy brings

Your X4 Pro, expanded — with games, speed, and control.

⚖

Game Boy Emulation

Built-in Game Boy and Game Boy Color emulation powered by Peanut-GB and Walnut-CGB. Drop your ROM files on the SD card and start playing straight away.

⚡

Faster Refresh

A custom waveform LUT drives the e-ink panel roughly 2.5× faster so games are actually playable and the reader feels snappy.

☰

Custom Buttons

Configurable button shortcuts for the reader and games. Map any action to any hardware button for your own workflow.

Installation

Get running in minutes

Install via web flasher or SD card. Then load your ROMs and start playing.

01

Download the firmware

Grab the latest firmware.bin from the GitHub Releases page.

02

Flash the device

Flash via the web flasher or copy to your SD card. The installer handles the rest.

03

Drop your ROMs

Copy Game Boy or Game Boy Color ROM files onto the SD card.

04

Play

Open the Game Library on your X4 Pro, select your ROM, and start playing.

⚠ Important note about display lifespan

Ink-boy uses a custom waveform LUT that drives the e-ink panel outside of its normal operating parameters. This increases the refresh rate by roughly 2.5× but may shorten the display lifespan. You can disable the fast refresh rate in settings for a safer experience.
